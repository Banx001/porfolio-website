01 Car Sales Insights Dashboard

Summary

Built to better understand car pricing and vehicle characteristics using real listing data, with a focus on the factors that actually influence value. Rather than treating price as a single number, the dashboard highlights how vehicle features — mileage, engine volume, body type, drive mode — contribute to where a car sits in the market.

Key Metrics

Total Cars: 8,739 Max Price: 547,800 Min Price: 259.35 Highest: Land Rover Range Rover Lowest: GAZ-21

Tools Used

Power BI DAX Power Query Excel

How It Was Built

  • 01 Imported and cleaned real car listing data using Power Query — standardised columns, removed duplicates, and handled missing mileage and price values.
  • 02 Built KPI cards showing total cars, highest and lowest priced vehicles, max and min prices, mileage extremes, and engine volume limits.
  • 03 Created a Market Overview page with Top 10 and Bottom 10 car types by price, body type distribution, and engine type breakdown.
  • 04 Built a Vehicle Features page showing mileage by car count, car count by year made, drive type distribution, and registration label breakdown.
  • 05 Used DAX to calculate aggregated pricing metrics, percentage breakdowns by engine type, and comparative ranking across brands.

03 Daily Household Transactions Dashboard
Power BI DAX Power Query
+

Summary

In most households, daily spending happens so automatically that we rarely pause to track it. This dashboard was created to address that gap — turning four years of scattered household transactions into a clear, organised financial story. It enables informed planning, smarter budgeting, and better financial decisions by making spending patterns visible across categories, years, and payment methods.

Key Metrics

Total Spent: INR 1,253,708 Max Transaction: INR 50,000 Avg Amount: INR 688 Amount Invested: 21.52% Top Sub-Category: Home (INR 204,506)

Tools Used

Power BI DAX Power Query Excel

How It Was Built

  • 01 Imported and cleaned four years of raw household transaction records — standardised categories, resolved date formats, and flagged inconsistent payment entries.
  • 02 Built a yearly spending trend chart (2015–2018) revealing peak spending in 2017 (INR 464,870) and a subsequent decline in 2018 (INR 393,633).
  • 03 Created a Top 10 Sub-Category breakdown: Home (INR 204,506), Public Provident Fund (INR 150,000), Bike (INR 94,593), and Appliances (INR 82,081).
  • 04 Grouped transactions into broad categories — Investment, Money Transfer, Transportation, Household, Food, Family — for high-level comparison.
  • 05 Added a Mode of Payment breakdown: 78% Saving Bank Account, 14% Credit Card, 8% Cash — surfacing payment preferences and transaction patterns.
